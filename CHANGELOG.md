# Changelog

## [0.5.0] - 2026-09-25

Latest recovered implementation. First public packaging prepared 2026-10-19.

- Two capture approaches: **Orbit Target / Sphere** and **Fixed Position / Look Around**.
- Adaptive latitude rings, exact-count Fibonacci distribution and legacy 26-camera hemisphere.
- Reference camera matching, target modes and framing-preserving radius/lens control.
- Evaluated mesh/Geometry Nodes ground clearance filtering.
- Selective render queue with progress, interruption retries, Stop and reset controls.
- Image resolution presets, compositor toggle, PNG/JPEG/OpenEXR output and optional `transforms.json`.
- Public distribution: Blender Extension manifest, license, documentation, repeatable build and release tests.

Existing operator identifiers and saved scene property names are unchanged from the recovered 0.5.0 source.
