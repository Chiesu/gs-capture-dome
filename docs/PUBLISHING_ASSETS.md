# Recommended GitHub presentation assets

The add-on is ready to publish without images. Real screenshots are recommended after running it in Blender. Do not use conceptual mockups to imply tested functionality.

Recommended assets:

1. `assets/dome-overview.png` - 1600x900 viewport screenshot showing the subject, wireframe dome and generated cameras. Set as the main repository image.
2. `assets/modes.png` - 1600x900 side-by-side of Orbit Target and Fixed Position / Look Around rigs.
3. `assets/render-ui.png` - 1200x900 capture of the GS Capture sidebar with Output and Render sections visible.
4. Optional `assets/rig-in-motion.gif` - under 8 MB, demonstrating regeneration or reference-camera movement.

Use actual UI capture, no stylized fake interface. Crop visible object names if they contain client/private information. Avoid uploading proprietary `.blend` scenes, commercial assets or personal file paths.

When those files exist, add the strongest one immediately below the README title. The release package does **not** require them to install.
